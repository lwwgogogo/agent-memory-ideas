# Idea 1：证据重复计数独立验证

仅使用远程服务器现有工作区；历史实验冻结，不使用 Mem0，不查文献，不扩到其他想法。

## 预先固定的设计

先运行数学实验，通过门控再运行行为实验。20 个虚构场景，五个领域各四个；六条件，每条件两个顺序种子 17、43，总计 240 次调用。模型 qwq:32b；温度 0；模型种子 20261004；上下文 4096；最大输出 768；Ollama JSON 模式。提示模板见 run_llm_test.py，配置持久化到 results/config.json。仅打乱记忆顺序，内容不随种子改变。全部任务以固定种子 905 打散。重复的单源调用仅用于一致性检查，统计时先在场景内平均，不把调用次数当样本量。

confidence 始终是 P(H1)，避免选择翻转导致置信指标方向错误。严格解析整个 JSON、字段集合、数值范围、重复键和选择一致性；失败标记 UNRESOLVED，不提取子串、不猜测、不用结果导向重试。

## 完整性与边界

原始观测为单个事实命题；五条派生记忆保持原命题，仅改变中性表述外壳。每例记录逐条事实映射与人工语义核验结论。反思只回顾原观测，不加入因果或确定性结论。独立条件在虚构生成机制中明确给定 H 下独立；真实世界类似观测未必独立。领域不同，但共用语法模板，因此不能宣称跨推理结构泛化。

长度控制按汉字字符数匹配，实际模型 token 数单独报告，字符数相等不保证 token 相等。五条记忆没有整条精确重复，但事实核心重复且近重复程度高，不能据此排除所有重复效应。没有额外精确重复条件，也不增加基准规模；如果效应只能由近重复解释，不能给 GO。来源提示与独立性提示可能有指令效应；本实验只评估行为现象，不识别内部计算机制。

## 预先固定的统计与判定

以场景为配对单位，场景内平均两个种子；只有审计通过且六条件两次均解析成功的完整场景进入主统计。报告均值、中位数、样本标准差，配对差值及场景级一万次自助法 95% 区间。另报各条件可用场景和逐种子方向检查。DCR 为均值 CI5/均值 IEG，同时报告分母近零的不稳定性；每例 IEG 非零时另报个体 DCR，零值不计算。

稳定膨胀要求 CI5 的配对区间下界大于零且两个顺序种子方向一致；无稳定膨胀则 NO_GO。有稳定膨胀但不能排除替代解释则 WEAK。GO 另需总体 D5>D3>C0、IEG 与 PC 区间下界大于零、D5−长度控制区间下界大于零、至少四个领域 CI5 为正，并有充分证据排除近重复及措辞效应。本紧凑模板设计不能完全排除后两者，因此出现膨胀也保守判为 WEAK。若完整场景不足 16，不能把缺失解析当无效应，应明确实验不充分并保守报告 NO_GO（不构成否定假设）。

数学图为三个独立画布。运行：python simulate.py；python generate_cases.py；python run_llm_test.py；python evaluate.py。不下载模型，不改变服务配置，不终止未知进程。

## 格式协议修订（正式统计前）

首轮普通 JSON 模式 240 次调用中 163 次不符合严格输出要求，主要包含空对象，全部保留在 results/format_diagnostic，不用于效果统计。单条格式检查验证严格 JSON Schema 可返回要求字段。模型、场景、温度、种子、输出长度和提示均不改变，仅将 JSON 模式升级为字段级 Schema；完整重跑固定 240 次，不按置信度筛选或单独补跑失败条件。此修订由解析故障触发，不依据效果大小。正式统计只用重跑结果，仍保留所有 UNRESOLVED。

环境：系统 Python 3.8.10，matplotlib 3.1.2；Ollama 0.5.12；模型 qwq:32b（列表 ID cc1091b0e276）；服务自动将模型放置在空闲 GPU 0（RTX 4090），约 20GB 显存，其余 GPU 空闲。已有 conda 位于 /home/liaoweiwen/miniconda3，当前未激活；不安装依赖。

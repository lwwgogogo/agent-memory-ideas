# Successful Experience ≠ Causal Evidence

历史经验 D_M={(x_t,a_t,y_t)} 来自 a_t∼π(a|x_t)，不是对动作的随机试验。一般情况下 P(Y|A) 与 P(Y|do(A)) 不相等；无混杂或特殊参数下可以相等，不能把不等号当成无条件定理。

## 最小世界

P(S1)=P(S2)=0.5。S1 中两动作成功率都为 0.9，S2 中都为 0.2。历史策略在 S1 选择 A 的概率为 γ，在 S2 选择 A 的概率为 1−γ，因而 P(A)=P(B)=0.5。

由贝叶斯公式，P(S1|A)=γ、P(S1|B)=1−γ，故：

- P(Y=1|A)=0.2+0.7γ。
- P(Y=1|B)=0.9−0.7γ。
- observational gap=1.4γ−0.7。
- 对未来均匀状态分布固定动作：P(Y=1|do(A))=P(Y=1|do(B))=0.5×0.9+0.5×0.2=0.55。
- causal gap=ATE(A vs B)=0。

γ=0.5 时观测差为零；混杂增强时观测差增大，而每个状态内部两动作完全等价。因果图为 X→A、X→Y，动作本身对 Y 没有效应。识别依赖本生成机制的稳定性、状态充分性与正支持性；这些并非任意现实日志的保证。

## 与记忆的关系

Policy → Experience → Memory → Future Policy。因此 experience memory 是 endogenous data：记忆的内容分布受此前策略影响。成功经验的频率不等于动作干预效用；汇总掉状态可能丢失调整所需的信息。

本实验只控制输入模型的历史经验记忆，未实际训练策略、形成长期记忆或运行闭环。计数取生成概率的精确整数实现，避免有限采样噪声；这是机制反例，不是新因果理论。AggregateSummary 删除状态信息后无法仅由汇总识别干预概率，因此其偏差不能单独证明模型推理失败。ConfoundedMemory 保留全部状态、动作和结局计数，才是核心行为检验；StratifiedOracle 只显式计算同一份数据的分层成功率，不直接给出因果结论。

# 预注册方案

日期：2026-09-30。正式运行前冻结；本文件之后不得因结果修改核心协议。

## 数据与条件

每个 episode 由 generator 生成 candidate evidence、ground-truth support set、transformation chain、visible trace、hidden trace、final memory 和 final claim。source structure 固定为 S1 single-source、S2 multi-source、S3 redundant support、S4 alternative support、S5 conflicting sources、S6 high semantic overlap。transformation 固定为 T0 identity、T1 paraphrase、T2 summary、T3 merge、T4 rewrite、T5 multi-step summary+merge+rewrite。compression 固定为 0.0、0.2、0.4、0.6、0.8；trace completeness 固定为 1.0、0.8、0.5、0.2、0.0。

compression 通过删除 evidence-specific token、source marker 和 support-specific wording 实现；不是只改格式。trace completeness 决定 hidden transformation steps 中有多少 metadata 对 baseline 可见，0.0 只保留 final memory/claim。

## Baselines 与 oracle

B0 Random；B1 lexical token-overlap；B2 visible-trace backward heuristic；B3 semantic embedding 若本地可用，否则记录 SKIP_WITH_REASON。O1 Full-Trace Oracle 读取完整 lineage；O2 Observation Identifiability Upper Bound 按 observation equivalence class 的多数标签计算，不读取 hidden truth 直接作答。

## 规模与统计

固定 seeds 0–19；每个 seed、source structure、transformation、compression、trace completeness 生成 10 episodes。输出 per-seed 和 per-condition 结果，并对 seed 做 bootstrap 95% CI。

## 指标

support exact match、precision、recall、F1、top-k recall、collision discrimination accuracy、ambiguity rate、identifiability upper bound。multi-source support 按集合计算。

## 判定

GO 必须同时满足：至少两类非 pathological source structure 中 best deployable baseline F1 因 compression/trace loss 下降至少 10pp；identifiability upper bound 下降至少 10pp；ambiguity rate 增加；Full-Trace Oracle 与 deployable baseline 有稳定 gap；不是只有 exact collision；主要趋势 CI 支持。

BORDERLINE：主要 effect 为 5–10pp，或只在 exact collision/强压缩出现。

NO-GO：简单 baseline 接近 Full-Trace Oracle、upper bound 基本不下降、普通 summary/rewrite 不增加 ambiguity，或只有硬编码 collision 才失败。NO-GO 后不改 threshold。

禁止 post-hoc 修改 seed、family、metric、threshold、baseline 权限或 Oracle 信息。额外实验必须标记 POST_HOC_EXPLORATORY。

# 实验结果

## 1. 研究问题与协议

本实验按预注册方案执行，目标是判断有损 memory transformation 后 provenance 是否在 observation 层面不可识别。没有运行 GPU、RL、JitRL、WebArena 或复杂神经模型。

## 2. 数据规模

正式运行使用 20 个 seed、6 类 source structure、6 类 transformation、5 个 compression level、5 个 trace completeness level，每个条件 10 个 episode，共 180,000 个 episode。4 个单元测试全部通过。

## 3. Baselines 与 Oracles

运行了 Random、Lexical、Trace-aware Heuristic 和 Full-Trace Oracle。Semantic embedding 因没有必要的本地模型而未运行，原因写入运行限制；LLM attribution 没有 API，不阻塞主实验。

## 4. Overall Results

整体 support F1：Random=0.667，Lexical=0.717，Trace-aware Heuristic=0.774，Full-Trace Oracle=1.000。观察到的整体 identifiability upper bound 约为 0.948，整体 ambiguity rate 约为 0.099。

## 5. Compression Analysis

预注册假设要求 compression 增大时 upper bound 下降。但在跨 source/transformation 的 trace=0 汇总中，upper bound 约为：compression 0.0: 0.522，0.2: 0.633，0.4: 0.713，0.6: 0.772，0.8: 0.854。方向与 H1 相反。原因是当前 synthetic generator 在强压缩后使 support label 分布更偏向 majority，majority-optimal upper bound 因此上升；这不能解释为信息变多。

## 6. Trace Completeness Analysis

trace-aware heuristic 在 visible trace 完整时接近 oracle，在 trace 被截断时明显下降；但 observation-level upper bound 没有形成预注册要求的稳定单调下降。因此 H2 没有被确认。

## 7. Collision Analysis

生成器确实建立了 observation equivalence class，并且测试验证了 exact collision 的不同 support 可以映射到同一 observation，collision upper-bound 单元测试通过。可是批量结果中的 ambiguity 主要受 source structure、seed 和 support distribution 影响，没有显示 compression 单调造成 collision 增长的证据。不能把少数 exact collision 外推为普遍不可识别性。

## 8. Identifiability Analysis

upper bound 与 deployable baseline 的差距说明存在 estimator weakness，但不满足“compression 导致 information-theoretic identifiability 稳定下降”。因此本轮没有达到 GO 所需的双重证据：baseline 下降且 upper bound 同步下降。

## 9. Source Structure Analysis

S1 single-source 最容易；S2/S3 多源结构的集合 support 更难；S4 alternative 和 S5 conflicting 的结果受随机 support 先验显著影响；S6 overlap 能产生更近的 observation，但当前模板仍不足以证明现实自然语言 summary 中的普遍不可识别性。

## 10. Failure Cases

本轮最重要 failure case 是实验设计自身的 confounding：compression 同时改变了 observation 内容和 support label 的可见分布，导致 majority upper bound 可能升高。这个结果杀掉了“只要 compression 增大，identifiability 必然下降”的宽泛假设。

## 11. Limitations

模板自然语言非常简单；没有真实 LLM summary/merge/rewrite；没有 embedding 或 LLM attribution；collision 规模和 support prior 仍需更严格平衡；当前 upper bound 按 observation class 的多数 support 计算，未引入结构化先验。

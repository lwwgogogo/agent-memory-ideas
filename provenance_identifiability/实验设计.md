# 实验设计

## 可观测性

latent history 包含 evidence、真实 support、transformation chain 和 hidden trace。observation 由 final claim、final memory 和按 trace completeness 保留的 visible trace 组成。baseline 永远不能读取 hidden trace、ground-truth support 或 generator labels。

## Collision

generator 为每个 observation 建立 equivalence class。exact collision 要求 latent provenance 不同且 observation 完全相同；near collision 使用 token Jaccard 至少 0.8 且 provenance 不同。upper bound 是每个 observation class 的多数 support label accuracy。

## 解释原则

如果 upper bound 随 compression 降低，说明是 information loss；如果 upper bound 不降但 baseline 降低，说明主要是 estimator weakness；如果二者都不变，则 Problem NO-GO。Full-Trace Oracle 只作信息上界，不代表可部署方法。

# 实验设计

每个 pair 共享最终 task 和 claim semantics，只改变 provenance identity。S1 使用单一 source，S2 使用 joint support，S3 使用 balanced alternative support。每个 pair 经过相同 transformation level 和 trace deletion。observation 由 final memory、claim 和可见 trace 组成，hidden provenance 不进入 baseline。

在 balanced 数据上按 observation equivalence class 计算 P(P|O=o)，再求条件熵与 Bayes accuracy。label shuffle、no-loss 和 exact collision 是正式 controls。若 label balance 失败，运行状态为 INVALID_EXPERIMENT，不解释 MI。

# 最终结论

## 最终 Verdict

```text
BORDERLINE
```

## 1. provenance information 是否随 transformation 丢失

在 balanced prior 控制后，L4 strong merge 和 L5 exact collision 确实降低了 MI；L0–L3 没有降低。证据支持“真正删除 provenance cue 会减少 P 与 O 的信息”，但只在 L4/L5 的模板条件中稳定出现。

## 2. 从哪个 level 开始

L0、L1、L2、L3 的 level-aggregate NMI 都是 1.0。L4 开始下降，T_partial≈0.654、T_final_only≈0.647；L5 在 T_partial/T_final_only 降到 0。

## 3. information loss 还是 estimator weakness

L4/L5 中 MI、conditional entropy、Bayes Accuracy 和 baseline F1 同步变化，因此更接近 information loss。L0–L3 中 baseline 没有下降，也没有 estimator-only failure。

## 4. single-source 与 multi-source

三类 source structure 都严格 balanced。S3 alternative support 体现 non-unique explanation，但只在 provenance cue 被合并或删除后才出现明显 ambiguity。当前不足以声称 multi-source 在中等 transformation 下普遍更早退化。

## 5. trace completeness 的作用

T_full 可以保留 provenance-specific trace，使 L4/L5 仍可被识别；T_partial 和 T_final_only 删除该 trace 后，L4 明显下降，L5 exact collision 达到理论 chance。trace 是当前实验中最直接的 information carrier。

## 6. 是否进入真实 LLM Phase B

暂不直接进入真实 LLM Phase B。因为 GO threshold 要求至少两个 source structure 在 L2/L3/L4 出现 >=0.15 的 NMI 下降，而本轮主要 degradation 在 L4/L5，且 L5 是明确的 positive control。按照冻结标准，不能判 GO。

## 7. 下一步

不再继续修改第三版 synthetic generator。若要继续，只能新注册一个更严格的 follow-up，增加 balanced semantic cue ladder、独立 source-structure 统计和 bootstrap CI；否则切回 Candidate 02 或做真实 Agent failure discovery。v1 的 NO-GO 和 Candidate 01 的 NOVELTY_NO_GO 均保持不变。

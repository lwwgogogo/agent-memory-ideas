# 预注册方案

正式运行前冻结：40 seeds；每个 seed、S1/S2/S3、L0–L5、T_full/T_partial/T_final_only 各 100 个 balanced pairs。每个 pair 两个 provenance label 严格一比一，task semantics、claim、pair transformation depth、evidence count 和 trace deletion rule 相同。

L0 Raw、L1 Paraphrase、L2 Mild Summary、L3 Abstract Summary、L4 Strong Merge、L5 Exact Collision。L5 只作 positive control，不单独证明现实性。trace levels 为 T_full、T_partial、T_final_only。

指标：H(P)、H(P|O)、MI、NMI、Bayes Accuracy、Bayes Error、ambiguity/collision rate，以及 Random、Lexical、Trace-aware、empirical Bayes、Full-Trace Oracle 的 F1。

GO：至少两类 source structure 在 L2/L3/L4 中 NMI 下降至少 0.15、Bayes Accuracy 下降至少 10pp、controls 通过且 95% bootstrap 支持方向。BORDERLINE：NMI 下降 0.05–0.15 或只在强压缩出现。NO-GO：中等 level NMI 基本不降、只有 L5 下降、no-loss 同样下降、或主要由 generator artifact 驱动。

禁止修改 seeds、label balance、threshold、metrics、baseline 权限和主协议。额外运行必须标记 POST_HOC_EXPLORATORY。

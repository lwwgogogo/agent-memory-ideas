# 实验结果

## 1. 为什么需要 v2

Phase A-v1 仍然是 NO-GO。v1 的 compression 同时改变 observation 和 support-label distribution，导致 majority upper bound 从约 0.522 上升到约 0.854，无法回答 information loss。v2 通过 counterfactual pair 和严格 50/50 label balance 重新隔离该问题。

## 2. Balanced Counterfactual Protocol

正式运行使用 40 seeds、3 类 source structure、6 个 transformation level、3 个 trace level、每个 condition 100 个 pairs，共 216,000 个 pair instances。每个 pair 由 label 0 和 label 1 各一个 history 构成；所有正式 condition 的 label count 完全相等。

## 3. Label Balance Check

`label_balance_check.csv` 中所有 condition 的 label0 与 label1 均为 100/100，最大比例差为 0.0，实验有效。

## 4. Controls

L0 raw、L1 paraphrase、L2 mild summary、L3 abstract summary 的 NMI 均为 1.0。说明这些模板仍保留可区分 provenance cue。T_final_only + L5 exact collision 的 NMI=0、Bayes Accuracy=0.5，符合 positive control 理论值。label shuffle 的理论 MI=0。

## 5. Mutual Information Results

按 level 汇总时：L0=1.000、L1=1.000、L2=1.000、L3=1.000、L4=0.767、L5=0.333。L5 的 level 均值被 T_full 中仍保留的 label-specific trace 拉高，因此必须按 trace 解读；T_partial 和 T_final_only 的 L5 NMI 均为 0。

## 6. Conditional Entropy Results

总体 level 汇总的 H(P|O) 为 L0–L3=0，L4≈0.233，L5≈0.667。T_final_only 的 exact collision 使 H(P|O)=1 bit，正好等于 balanced binary label 的 H(P)。

## 7. Bayes Bound Results

总体 level 汇总 Bayes Accuracy 为 L0–L3=1.000、L4≈0.892、L5≈0.667。对于 L5 + T_final_only，Bayes Accuracy=0.5，Bayes Error=0.5，符合理论上限。

## 8. Baseline Results

Full-Trace Oracle 的 F1=1.0。L0–L3 lexical baseline 可以利用模板 cue 达到 1.0；L4 lexical F1≈0.825；L5 lexical F1≈0.5。Trace-aware baseline 在 T_full 能利用 trace，但在 T_partial/T_final_only 受到限制。baseline 下降与 L4/L5 的 MI 下降方向一致，但 L0–L3 没有 estimator failure。

## 9. Source Structure Results

S1 single-source、S2 multi-source、S3 alternative 都遵守 balanced prior。S3 的 alternative support 代表非唯一解释，但在 L0–L3 仍有可见 cue；不可识别性主要在 L4/L5 和 trace 被删除时出现，而不是自动存在于所有 multi-source 条件。

## 10. Trace Results

L4 + T_full 的 NMI=1.0，L4 + T_partial≈0.654，L4 + T_final_only≈0.647。L5 + T_full=1.0，L5 + T_partial=0，L5 + T_final_only=0。说明 trace completeness 在当前控制中决定是否仍保留 provenance-specific identifier。

## 11. Collision Results

L5 + T_final_only 是 balanced exact-collision positive control，NMI=0、Bayes Accuracy=0.5。L4 产生 near-collision，NMI 已下降但尚未归零。exact collision 不能单独证明现实性，因此 GO 仍需要中等 level 的非 pathological degradation。

## 12. Estimator Weakness vs Information Loss

本轮与 v1 不同：L4/L5 中 MI、Bayes Accuracy 和 baseline F1 同方向变化，支持 information loss，而不是单纯 estimator weakness。另一方面，L0–L3 MI 保持 1，说明 paraphrase 和当前轻度 summary 模板没有删除 provenance information。

## 13. Limitations

当前仍是 deterministic/template synthetic experiment，没有真实 LLM transformation；semantic embedding 与 LLM attribution 未运行；L4 的 stochastic shared cue 仍较人工；尚未完成 bootstrap CI 和独立图形渲染。当前结果可以支持更窄的 synthetic information-loss claim，但不能直接外推到现实 Agent Memory。

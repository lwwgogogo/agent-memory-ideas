# Phase A.1 与 A.2 执行前方案

2026-09-29，参考《Agent Memory 三条研究 Idea 备忘录》2.5/2.6：先在线 Bayesian/HMM，再决定复杂机制；匹配信息后 Oracle 无明显优势则停止。经典算法仅作为强 baseline。

## A.1 本轮执行

维持原 25 格 stationary 环境、T=2000、burn-in=100。验证种子沿用100–109；测试使用未用于上次讨论的新种子40–59。固定 baseline 候选完全不变。增加均匀离散 Q/R 先验的 Bayesian 模型平均，不使用真实 Q/R、状态标签或 per-cell 验证结果。49 个模型的网格独立写进配置；没有根据本轮结果调网格。

模型权重按 assimilation 前的 predictive likelihood 更新，状态后验再按更新后的模型权重混合；这是联合参数/状态 Bayes 的分解，不是重复使用观测。log 权重避免长序列下溢。默认假设 Q/R 在轨迹内固定，不声称适应参数突变。

主要报告 global/per-cell/online/Oracle 的 accuracy 和 paired seed bootstrap 区间，补充原有失败指标。报告在线方法追回的 Oracle-global gap 比例；分母接近零时不解释该比例。Q/R 后验均值只用于诊断，不能由高准确率推断参数已被唯一识别。

本轮探索性决策参考：若在线方法追回至少80%的 Oracle-global accuracy gap，且 Oracle-online gap 不超过1个百分点，则普通在线方法已足够强，不继续包装 stationary 场景的新更新公式。这是本轮运行前设定的工程研究阈值，不是文献标准或正式预注册。未满足也不能证明新方法必要，应先查模型离散化与有限观测学习误差。

## A.2 仅冻结设计，本轮不执行

应用动机：工具可靠性随时段变化，或用户/环境状态的变化频率改变。仍为 synthetic，不声称已证明真实 Agent 存在同样效果。

T=3000，burn-in=100。Q-only：Q从0.005变为0.15，R固定0.2；R-only：R从0.05变为0.35，Q固定0.01；temporary corruption：Q固定0.01，R从0.05变为0.45持续100步再恢复。对前两类也做反方向切换。切换起点从[900,1500]离散均匀采样，不告知方法；保留stationary负对照。

验证seed200–219，测试seed300–339；只能在验证集选window/forgetting参数。所有方法共用轨迹，模型不接收变化时刻、类型或新Q/R。对照包含固定方法、普通BMA、带遗忘模型权重、滑动窗口估计，以及知道每步真实Q/R但不知道状态的Oracle。

主要指标：全程accuracy、变化后50/100/300步错误率，以及连续10步正确的恢复延迟和删失比例；temporary corruption另报污染期间与恢复后错误率。区间按seed配对重采样。不同场景单独报告，不用总体均值遮盖失败。带遗忘BMA只是一种启发式强对照，不能当作精确非平稳Bayes。

建议继续机制研究的门槛：至少两类预定变化场景中，Oracle相对验证选出的最强可部署对照仍有至少2个百分点全程accuracy空间，且固定窗口错误率也有改善，stationary不能明显退化。届时先分析信息可辨识性，再设计方法；如果空间仍很小，停止Idea1复杂路线并考虑独立Idea3。该阈值也仅是提前固定的研究决策规则。

# 当前研究原则

Memory-native phenomenon
↓
False equality
↓
Mathematical abstraction
↓
Minimal counterexample
↓
GO / NO-GO
↓
只有 GO 后才查重和设计方法

先明确可被证伪的现象和错误等同，再做最小数学反例及行为检验。NO-GO 不代表否定所有可能世界，只表示当前路线缺少推进证据。

- 不为了模仿 SkillProj 强行套 subspace。
- 不为了得到正结果修改实验、换模型、调整提示或不断扩样。
- 有 close work 不等于自动 NO-GO；只有到达对应阶段才做文献判断。
- 不先建大 benchmark。
- 不先调复杂真实系统。
- 固定生成机制、解析规则和门槛，保留失败响应；对解析故障与研究信号分开报告。
- 因果等价的 ground truth 由生成机制确定，不能只凭相关性推断。
- 数学成立不等于 LLM 必然出现该行为，也不等于已证明 novelty。

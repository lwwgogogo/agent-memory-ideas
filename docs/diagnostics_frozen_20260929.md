# D1 D2 运行前冻结补充

不改变旧输出与旧生成器。D1按用户指定沿用测试40–59（与之前执行记录建议新seed不同，以本次明确要求为准），保留100–109验证、25格、T2000、burn-in100及全部原固定baseline候选。

Dense主配置：25个logspace Q点覆盖[.001,.5]，21个linear R点覆盖[0,.5]，再并入全部原49模型坐标及全部evaluation轴值，非逐格挑点。参数先验均匀。网格独立保存并在test执行前冻结。覆盖evaluation参数仅提供可能值集合，不告知当前条件。

加密会改变离散先验分布，因此额外报告dense_prior_matched：在log-Q/linear-R最近邻旧节点分区中，每个原节点分配相同总先验质量，再均分到该分区dense节点。这不是完全相同连续先验，但控制粗区域先验质量，避免把所有改善都叫离散化效果。主决策仍用预先固定的uniform Dense，不从test选择先验。

D2是exploratory。原生成器在转移抽样之后抽初始状态，独立调用不同T不保证同前缀。保留原函数，用每seed的10000步轨迹截取2000/5000/10000前缀；统计分布保持，D2 T2000不必与D1逐样本一致。沿用40–59固定种子，不能将其解释为新的confirmatory证据。窗口为[100,500)、[500,1000)、[1000,2000)、[2000,5000)、[5000,10000)，同时记录对应时刻后验和每100步收敛轨迹。

区间5000次paired seed bootstrap，格点汇总先按seed等权平均。率缺失不填0。所有对比存储reference-minus-method；Brier/error正差代表reference更差，不混淆符号。决策按预设点估计门槛，同时报告CI；不追加test调参。

D1/D2输出目录新建且禁止覆盖；每次开始存source_snapshot.zip、源hash、完整配置、环境，结束存耗时与输出hash。A2只有两项诊断完成并通过stationary门槛后执行；否则先输出INCONCLUSIVE诊断。
